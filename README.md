# Linsa Vinod &mdash; Personal Portfolio & Systems Showcase

🌐 **Live URL**: [https://linsavinod.github.io/portfolio/](https://linsavinod.github.io/portfolio/)

A modern, responsive developer portfolio showcasing projects in network packet analysis, anomaly detection, machine learning, and full-stack engineering.

---

## ⚡ Key Highlights
- **Interactive Network Canvas**: Particle simulation visualizing data flows, packets, and node links.
- **Simulated Terminal Engine**: Interactive CLI demonstrating the NetGuard packet analyzer with libpcap and Isolation Forest detection telemetry.
- **Projects Showcase**: Deep-dive modals and architecture overviews for:
  - **NetGuard**: C, Linux, Libpcap, Scikit-learn, Pandas, Wireshark
  - **Network Anomaly Detection Dashboard**: FastAPI, React, Scikit-learn, PostgreSQL
  - **Study Guide Builder**: Generative AI, JavaScript, HTML, CSS
- **Interactive CV**: Digital resume view with instant one-click PDF printing.
- **Dark Cyber & Minimalist Light Themes**: Persistent theme switching with custom design system.

## 🚀 Deployment
Automatically built and hosted via **GitHub Pages** using GitHub Actions (`.github/workflows/deploy.yml`) and the `gh-pages` branch.

### Local Development
Open `index.html` directly in any web browser, or launch a lightweight HTTP server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
